# Daily AI News（每日 AI 简报）

## 一句话定位

从多个来源聚合并总结最新 AI 新闻，去重分类后输出带原文链接的每日简报。核心是提示词编排流程，可选运行 `scripts/generate_queries.py` 生成带真实日期的搜索查询。

## 适用场景

- "今天的 AI 新闻 / AI 有什么新动态 / 最新 AI 发展 / 每日 AI 简报"
- 快速了解最近 24–48 小时 AI 领域的重大公告、研究突破、行业融资、工具发布、政策伦理
- 需要按关注领域（研究 / 产品工具 / 行业融资 / 特定公司）定制简报

## 不适用场景

- 需要深度调研 / 多源互动数据排序的近 30 天趋势（转 `research.last30days`）
- 某个主题的一轮完整研究报告（转 deep-research 类流程）
- 不是"聚合新闻给摘要"，而是"给定主题出结构化报告"的调研需求

## 执行前需要的信息

- 时间范围：默认最近 24–48 小时；可指定 3 天 / 一周
- 可选：关注领域（研究 / 产品 / 融资 / 特定公司）、详细程度（简要 / 标准 / 深度）、组织方式（类别 / 时间 / 公司 / 重要性）
- 可选：搜索服务（WebSearch、Brave、Serper 等）通过环境变量注入

## 执行流程

1. **收集**：直接抓取 3–5 个主要新闻源（见 `references/news_sources.md`）；运行 `scripts/generate_queries.py`（或参考 `references/search_queries.md`）生成当日搜索查询，跨类别执行 2–3 个查询，每个取前 10–15 条
2. **筛选**：保留 24–48h 内的重大公告、产品/模型发布、研究突破、行业动态；去重（保留最全面版本）、排除营销与 >3 天旧内容
3. **分类**：🔥 重大公告 / 🔬 研究论文 / 💰 行业融资 / 🛠️ 工具应用 / 🌍 政策伦理
4. **输出**：按 `references/output_templates.md` 选择模板（标准默认 / 简要 / 深度），给出类别、标题、要点、影响与来源链接

## 交付结果

- 一份分类呈现的 AI 新闻简报（Markdown），每条含：摘要、要点、影响、来源出版物 + 链接
- 关键要点 1–3 条（当天最重要的发展）
- 生成时间与覆盖范围声明

## 默认边界

- **读文件**：是（为聚合而读用户指定的本地资料时）
- **写文件**：是（仅在用户要求保存简报时写用户指定路径）
- **执行命令**：否（生成查询是可选的辅助脚本，核心流程不依赖命令行）
- **网络**：是（抓取新闻源与执行搜索）

## 与相邻 Skill 的区别

| Skill | 区别 |
| --- | --- |
| `research.last30days` | 多平台互动数据排序的近 30 天趋势调研；本 Skill 是最近 24–48h 的新闻聚合简报 |
| `data.exploratory-analysis` | 本地数据画像/质量审查；本 Skill 无本地数据维度 |

## 行为案例

### 案例 1：每日简报

**输入**：用户说"今天有什么 AI 新闻？"

**预期行为**：抓取 3–5 个主要来源 + 搜索补充，按五类筛选去重，输出标准模板简报（类别、标题、要点、影响、来源链接），并询问是否需要调整关注领域/详细程度。

### 案例 2：信息来源不可用

**输入**：所有来源抓取失败、搜索无结果。

**预期行为**：扩大日期范围、换查询词或提高/降低重要性阈值；任一来源失败则跳过并尝试下一个；不编造新闻标题或链接。

### 案例 3：简报保存

**输入**：用户要求"把简报保存到文件"。

**预期行为**：仅写入用户指定路径；不修改其他文件、不触碰系统路径。
