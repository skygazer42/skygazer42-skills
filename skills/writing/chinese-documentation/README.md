# Chinese Documentation Standards（中文文档排版）

## 一句话定位

中文文档排版规范——中英文空格、全半角标点、术语保留、链接格式，遵循中文文案排版指北。

## 适用场景

- 撰写中文技术文档/README
- 审查中文文档的排版规范
- 团队统一中文文档风格

## 不适用场景

- 英文文档排版
- 代码规范（非文档排版）

## 执行前需要的信息

- 待排版的中文文档
- 可选：团队特定约定

## 交付结果

- 符合排版规范的中文文档

## 默认边界

- **读文件**：是
- **写文件**：是
- **执行命令**：否
- **网络**：否

## 与相邻 Skill 的区别

| Skill | 区别 |
| --- | --- |
| `writing.authentic-writing` | 去 AI 味写作，本 Skill 是中文排版规范 |
| `writing.humanizer` | 消除 AI 模式，本 Skill 是排版格式 |
