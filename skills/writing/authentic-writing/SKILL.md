# 去 AI 味写作

**核心洞察：去 AI 味的本质不是删 AI 特征，是写出作者自己。** 禁用「首先其次最后」「不是…而是…」、少排比、加口语——这些表面功夫只能把一种模板换成另一种模板。文章看不出经典 AI 腔了，但还是不像作者本人。真正的辨识度在更深的地方。

> 这是一套**写作专家系统**，不是一条提示词。提示词交代眼前这篇；系统保存作者积累的经验，不必每次从零开始。

## 三层规则：管什么

### 1. 作者是谁

不是每篇重复履历，而是让文章从作者真实的位置生长：

- **经历与视角**：作者经历过什么、习惯从什么角度看问题、和读者是什么关系。
- **事实边界（最关键）**：哪些能用第一人称讲；引用别人的经验该怎么说；**超出作者真正了解范围的判断，不能替他下**。
- 违反的后果：AI 很容易替作者编一段经历、加个立场、得出看似合理的结论——文字流畅，但**身份已经越界**。

### 2. 这类文章怎么写

不只是语气像不像，还有：怎么推进观点、什么时候给例子、哪里该停一下、长短句怎么配、结尾落到哪。

**按文章类型分，不同标准**：
- 教程：把步骤、结果、风险说清楚。
- 观点文：要有判断，也要让判断站得住。
- 只规定一种笼统文风 → 所有文章写成同一个模子。

### 3. 绝对不会写什么

- 防编造事实、防把别人的经历写成作者自己的、防不符身份的权威口吻。
- 作者反复规避的表达习惯（禁用表达清单）。
- **「稳定地不愿意写什么，往往更能说明他是谁」**——只说喜欢什么不够，稳定的「不写」更定义一个人。

## 初稿之后：多轮独立审稿

**初稿只算 60 分的第一版材料，不是成稿。** 规则一多，模型可能顾住结构忘了语气、记住风格又在某段回到自己最熟的表达。

做**几轮彼此独立**的审稿——每轮只承担一组明确任务、**重新读取对应的规则文件**、对着同一篇初稿改：

| 轮次 | 只看这一件事 |
| --- | --- |
| **第一轮：任务完成度** | 主线清不清楚、结构有没有跑偏、材料用得对不对、有没有缺关键论证 |
| **第二轮：像不像这个作者** | 个人风格有没有执行、文章类型对不对、和读者的关系符不符合主题 |
| **第三轮：AI 腔与禁忌** | 哪些句子只是听着完整实际没信息、哪些过于工整、有没有身份越界/编经历/命中禁用写法 |

- **每轮交给一个独立子 Agent**，效果比一个 Agent 审三次好（各带各的规则、互不干扰）。
- 严格对照标准，**别让写初稿的模型凭印象给自己打「没问题」**。
- 每轮哪些建议接受、哪些句子保留，**由作者决定**——审稿发现问题，但不替作者承担判断。

## 规则迭代：越用越像作者

每次审稿和人工修改都产生新的个人上下文。改稿时追问：原句哪里不对、为什么改、**是偶然还是反复犯**？

- 作者总删的口吻 → 补进禁用表达。
- 某类文章反复出同一个结构问题 → 调对应的类型规则。
- 作者形成的稳定判断 → 留下，免得 AI 下次给相反的通用答案。

**但不是每次局部改动都变永久规则**（这是剃刀）：
- 规则只增不减、不维护 → 越来越长、彼此打架，AI 不知道遵守哪条。
- **只有反复出现、影响大、下次可复用的才值得留**；冲突就合并、过时就替换。

## 整体循环

```
作者档案(是谁/边界/禁忌) → AI 写初稿 → 多轮独立审稿 → 作者定夺修改 → 暴露的新问题补回规则 → 下一篇从更准的起点开始
```

## 边界

- **读文件**：是（读作者档案、规则文件、初稿）。
- **写文件**：是（写初稿、改稿、更新规则文件）。
- **事实边界不可越**：不替作者编经历、下超出其了解范围的判断、用不符身份的权威口吻。
- **作者定夺**：审稿提问题，但接受与否、最终成稿由作者决定。
