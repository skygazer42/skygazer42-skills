# Wizard（向导生成）

## 一句话定位

生成交互式 bash 向导，引导人类逐步完成只有人能做的操作（配置基础设施、设置凭据、操作第三方控制台等）。

## 适用场景

- 配置基础设施/CI secrets
- 操作不熟悉的第三方控制台
- 一次性迁移或切换操作
- 需要人工输入但又不想每次都重新解释的流程

## 不适用场景

- Agent 自己能完成的操作（直接执行即可）
- 需要持久化的自动化脚本（向导是临时的）

## 执行前需要的信息

- 需要引导的操作流程
- 每个步骤需要捕获的值

## 执行流程

1. 阅读项目上下文（.env、workflows、README 等）
2. 确定每一步手动操作和需要捕获的值
3. 基于 template.sh 生成 bash 向导
4. 保存到 scratch/scripts/ 路径

## 交付结果

- 交互式 bash 向导脚本

## 默认边界

- **读文件**：是
- **写文件**：是
- **执行命令**：是（bash）
- **网络**：否
