# 探索性数据分析（Exploratory Analysis）

对用户提供的**本地数据文件**或对话内表格生成综合数据画像，理解其形状、质量和模式后再深入分析。本 Skill 不连接数据库、不访问远程仓库——只处理用户显式提供的数据。

## 使用前确认

1. 拿到数据：本地文件（CSV/TSV/JSON/Parquet/XLSX）或对话内表格均可。
2. 无数据时：向用户要文件或数据，不编造、不联网猜。
3. 默认**只读**源数据：不自动清洗、填补、删除异常值或覆盖源文件。

## 适用场景

- 拿到一个从未见过的新数据集，想先弄清形状、质量和模式
- 检查缺失率、列分布、基数、重复记录
- 发现可疑值、占位符、格式不一致、编码问题
- 判断哪些列适合做维度/度量，哪些时间列适合趋势分析
- 分享分析给利益相关者前，做方法论、准确性、偏差审查

## 工作流

### 1. 读取数据

1. 读取文件或对话内表格，推断各列类型。
2. 记录总行数、列数、粒度（一行代表什么）。
3. 无法读取时明确说明原因（格式不支持/文件缺失），不猜测内容。

### 2. 理解结构

按类型分类每一列：

- **标识符**：唯一键、外键、实体 ID
- **维度**：用于分组/筛选的分类属性（status、type、region）
- **度量**：用于测量的数值（revenue、count、duration）
- **时间**：日期/时间戳（created_at、event_date）
- **文本**：自由文本（description、notes）
- **布尔**：true/false 标志
- **结构**：JSON、数组、嵌套结构

### 3. 生成数据画像

**表级指标**：行数、列数与类型分布、时间列覆盖范围（min/max）。

**所有列**：
- 缺失数、缺失率
- 去重数、基数比（distinct / total）
- 最常见的值（top 5-10 及频率）
- 最少见的值（bottom 5，用于发现异常）

**数值列（度量）**：
```
min, max, mean, median (p50)
标准差
分位数：p1, p5, p25, p75, p95, p99
零值数、负值数（如预期外）
```

**字符串列（维度/文本）**：
```
最小长度、最大长度、平均长度
空字符串数
格式一致性分析
大小写一致性（全大写/全小写/混合）
首尾空白数
```

**日期/时间列**：
```
最小日期、最大日期
空日期数
未来日期（如预期外）
按月/周分布
时间序列缺口
```

**布尔列**：true 数、false 数、null 数、true 率。

**画像以清晰汇总表呈现**，按列类型分组。

### 4. 识别数据质量问题

- **高缺失率**：>5% 提醒，>20% 告警
- **低基数意外**：应高基数的列基数很低（如 user_id 只有 50 个去重值）
- **高基数意外**：应是分类的列却有过多去重值
- **可疑值**：只应正数的负值、历史数据里的未来日期、占位符（"N/A"、"TBD"、"test"、"999999"）
- **重复检测**：检查自然键是否唯一
- **分布偏斜**：极端偏斜的数值分布可能影响平均值
- **编码问题**：分类字段大小写混杂、尾随空白、格式不一致

### 5. 发现关系与模式

- **外键候选**：可能关联到其他表的 ID 列
- **层级**：自然的钻取路径（country > state > city）
- **相关性**：一起变动的数值列
- **派生列**：由其他列计算得出的列
- **冗余列**：信息完全相同或几乎相同的列

### 6. 建议值得分析的维度与度量

- **最佳维度列**：合理基数（3-50）的分类列
- **关键度量列**：分布有意义的数值列
- **时间列**：适合趋势分析
- **自然分组/层级**：数据中显现的分组
- **潜在连接键**：可关联其他表的 ID 列

### 7. 推荐后续分析（3-5 个）

- "按 [维度] 分组，对 [度量] 做按 [时间列] 的趋势分析"
- "对 [偏斜列] 做分布深入，理解异常值"
- "对 [问题列] 做数据质量调查"
- "[度量A] 与 [度量B] 的相关性分析"
- "用 [日期列] 和 [状态列] 做队列（cohort）分析"

### 8. 分享前审查（可选第二流程）

用户要求"分享前帮我检查这份分析"时，执行 validate-data 的流程：

- **方法论与假设**：问题框定是否准确、数据选择/时间段是否合适、人群定义是否有意排除、指标定义是否清晰一致、基准比较是否公平
- **常见陷阱目录**：join 爆炸、幸存者偏差、不完整期对比、分母漂移、平均值的平均、时区错配、选择偏差；其他统计陷阱（辛普森悖论、相关当因果、小样本、离群值影响均值、多重比较、前瞻偏差）
- **计算复核**：独立重算几个关键数、检查小计是否等于合计、百分比是否≈100%、环比基期是否正确、过滤器是否一致应用
- **可视化审查**：柱状图是否从 0 开始、比较图比例是否一致、标题是否准确描述、是否有误导性截断
- **结论审查**：结论是否被数据支持、是否承认替代解释、不确定性是否传达、建议是否从发现中逻辑推出
- **信心评级**：可分享 / 带注记分享 / 需修订

## 约束

- 不编造数据集内容、缺失率、基数、分布或结论——一切基于实际读到的数据。
- 默认只读源数据；允许另写 Markdown/JSON 报告，不自动清洗、填补、删除异常值或覆盖源文件。
- 不连接数据库/数据仓库，不访问远程数据源。
- 质量旗标是启发式的——不是每个旗标都是真问题，但每个都值得快速看一眼。
- 对非常大数据集，可注明使用了抽样，需要精确计数时先说明。

## 失败处理

- 无法读取文件：说明格式/路径问题，请用户提供支持格式或修复数据，不猜测内容。
- 数据为空或列数异常：如实报告，不编造统计量。
- 用户要求清洗/填补/删异常值：超出本 Skill 只读边界，明确说明需单独授权后另做。
- 用户要求连接数据库查询：v0.1 不支持，说明当前只处理本地文件，数据库查询为未来能力。

## 数据质量评估框架

**完整性评分**（每列）：
- 完整（>99% 非空）→ 绿
- 大体完整（95-99%）→ 黄，调查缺失
- 不完整（80-95%）→ 橙，理解原因和影响
- 稀疏（<80%）→ 红，无填补可能不可用

**一致性检查**：值格式不一致（"USA"/"US"/"us"）、类型不一致（数字存成字符串）、引用完整性（外键无父记录）、业务规则违反（负数量、结束早于开始）、跨列一致性（status=completed 但 completed_at 为空）。

**准确性指标**：占位符值（0、-1、999999、"N/A"、"TBD"、"xxx"）、默认值（单值频率异常高）、陈旧数据（活跃系统 updated_at 无近期变化）、不可能值（年龄>150、远期日期、负时长）、整数偏差（都以 0/5 结尾）。

**时效性评估**：最后更新时间、预期更新频率、事件时间与加载时间的滞后、时间序列缺口。

## 模式发现技术

**分布分析**：正态（均值≈中位数）、右偏（高值长尾）、左偏、双峰（两个总体）、幂律（少数超大值）、均匀（可能合成/随机）。

**时间模式**：趋势、季节性（周/月/季/年）、星期效应、假日效应、变点、异常点。

**分段发现**：3-20 个去重值的分类列、跨段比较度量分布、显著不同行为的段、同质性检验。

**相关性探索**：数值列相关矩阵，|r|>0.7 标记调查；明确标注"相关不代表因果"；检查非线性关系。
