# Brand Kit（品牌套件生成）

## 一句话定位

品牌套件图片生成——创建高端品牌指南板、Logo 系统、身份识别视觉方案，像出自专业品牌工作室。

## 适用场景

- 新品牌/产品的视觉身份体系设计
- Logo 概念与品牌隐喻探索
- 品牌指南板（grid layout）生成
- 品牌世界观展示
- 覆盖极简/电影感/深色科技/奢侈/开发者工具等品牌体系

## 不适用场景

- 页面级前端实现（转 `web.image-to-code` 或 `web.frontend-implementation`）
- 设计方向探索（转 `web.frontend-design` 先定方向）
- 需要交互原型的品牌展示（本 Skill 专注静态视觉板）

## 执行前需要的信息

- 品牌名称和核心隐喻
- 目标受众和行业
- 风格偏好（极简/电影感/深色科技/消费级等）
- 品牌色偏好（可有可无）

## 执行流程

1. 理解品牌核心隐喻
2. 确定视觉语言（配色/排版/质感）
3. 生成品牌指南板（grid layout: 3×3 或自定义）
4. 包含 Logo 概念、字体选择、色彩体系、品牌应用示例

## 交付结果

- 品牌套件概览图（含 Logo + 色彩 + 字体 + 应用示例）
- 品牌视觉体系说明

## 默认边界

- **读文件**：是
- **写文件**：否
- **执行命令**：否
- **网络**：否

## 与相邻 Skill 的区别

| Skill | 区别 |
| --- | --- |
| `web.frontend-design` | 定页面设计方向，本 Skill 是品牌视觉体系生成 |
| `web.image-to-code` | 图片→页面代码，本 Skill 是品牌板→视觉资产 |

## 行为案例

### 案例 1：典型品牌套件生成

**输入**：用户说"帮我做一个叫 'Nova' 的 AI 开发者工具品牌的视觉体系，深色科技风"。

**预期行为**：
1. 理解品牌核心隐喻（Nova=新星，AI 开发者工具）
2. 确定视觉语言：深色板+科技感配色+几何 Logo
3. 生成品牌指南板：Logo 变体、色彩体系、字体选择、UI 应用示例
4. 产出 3×3 grid 品牌板

### 案例 2：品牌风格不明确

**输入**：用户说"帮我设计一个品牌"但未提供行业和风格信息。

**预期行为**：
1. 先问清品牌名称、行业、风格偏好
2. 不生成泛化的"通用品牌"
