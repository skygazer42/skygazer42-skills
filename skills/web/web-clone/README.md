# Web Clone（网站 1:1 复刻）

## 一句话定位

对一个现有线上网站做 1:1 工程化复刻——镜像全部资产、逆向技术栈、对照产物逐行为溯源还原，核心规则是「有线索按线索、没线索不瞎猜」。

## 适用场景

- 用户想复刻/重建/逆向一个线上网站（学习、迁移、研究）。
- 没有源码，只能从编译产物重建工程。
- 站点重度使用 WebGL/Canvas/自研引擎，无公开文档。

## 不适用场景

- 从零做原创设计——用 `web.frontend-design`（意图相反：复刻要精确，设计要创意）。
- 实现单个新 UI 功能——用 `web.frontend-implementation`。
- 侵权且商用——先解决授权。

## 执行前需要的信息

- 源站 URL。
- 复刻目标范围（整站 / 某几个模块）。
- 用途声明（个人学习 / 有授权的迁移）。

## 执行流程

1. **镜像**：抓取全部资产到 `legacy-mirror/`，补录 worker-fetch / 懒加载 / mobile 三类漏网资产。
2. **逆向**：beautify 展开 bundle，逆向技术栈和私有格式，写 `engine-notes`。
3. **溯源移植**：换工程骨架，但核心逻辑逐函数对照移植，shader/常量逐字提取，死代码照抄。
4. **里程碑三重验证**：全新加载 + 无头回归（桌面+移动）+ 量化像素比对。
5. **收尾**：目视/截图抓剩余 bug，对照镜像找线索修。

## 交付结果

- 一个逐行为对齐源站的工程化复刻。
- `legacy-mirror/`（逆向依据）+ `engine-notes`（逆向笔记）。
- 三重验证的证据（无头回归日志 + 像素比对结果）。

## 默认边界

- **网络**：是（镜像阶段抓取源站）。
- **读文件**：是。
- **写文件**：是（重建工程代码）。
- **执行命令**：是（构建、无头浏览器、截图比对）。
- 授权风险 > 技术风险：默认按个人学习、不公开部署处理，产物保留声明。

## 与相邻 Skill 的区别

| Skill | 区别 |
| --- | --- |
| `web.frontend-design` | design 原创精品、创意自由；web-clone 精确复刻、不要创意 |
| `web.frontend-implementation` | implementation 实现新功能；web-clone 复刻整站 |
| `web.frontend-testing` | web-clone 的三重验证调用 testing 做浏览器回归 |

## 行为案例

### 案例 1：典型成功场景（重度 WebGL 创意站）

**输入**：用户说「帮我 1:1 复刻 oryzo.ai，学习它的 WebGL 实现」。

**预期行为**：
1. 镜像全站资产，发现 worker 运行时 fetch 的 WASM 排序器没抓到 → 从源站补录。
2. beautify 展开 1.1MB bundle，逆向出 `.buf`/`.sog` 私有格式和后处理链拓扑，写 engine-notes。
3. 换 Astro 骨架，但引擎逻辑逐类对照移植，GLSL 逐字提取，源站的死代码（错位的 `format="R8"`）照抄。
4. 分里程碑推进，每个里程碑全新加载 + 无头桌面/移动回归 + 与源站量化像素比对。
5. 真机对比发现切割垫场景偏亮 → 定位到缺一行 `colorSpace` 赋值 → 修复。

### 案例 2：边界/失败场景（凭感觉瞎猜）

**输入**：某动画帧区间在 bundle 里没直接标出。

**预期行为**：
1. **不得**凭画面感觉猜一个帧区间（如猜 47）填进去。
2. 回到 bundle 里找线索（搜索该常量的定义和消费点），找到真实值（71/116）。
3. 若确实找不到线索 → **标记「待查」**，不编一个看起来合理的值。
4. **不得**"优化"或"修正"源站的死代码/错位赋值。
