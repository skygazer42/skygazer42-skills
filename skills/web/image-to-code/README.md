# Image to Code（图片转代码）

## 一句话定位

图片优先的网站设计到代码——先让 AI 生成设计参考图，深度分析，再忠实还原为前端实现。专治 AI 生成"模板味"页面。

## 适用场景

- Hero 区域、landing page、营销站、品牌页、作品集
- 视觉优先的网页任务（不是数据表格/后台面板）
- 需要从截图或设计稿还原为代码
- 改版中视觉质量关键的项目

## 不适用场景

- 系统/后台/工具界面（转 `web.interface-design`）
- 纯功能实现无视觉需求（转 `web.frontend-implementation`）
- 品牌视觉体系设计（转 `web.brandkit`）

## 执行前需要的信息

- 设计 brief 或参考截图
- 目标页面类型（hero/landing/品牌页/作品集）
- 风格偏好（如 Linear 风/极简/野兽派/Apple 风）

## 执行流程

1. **生成设计图**：先让 AI 生成各区域的设计参考图
2. **深度分析**：分析图的排版、配色、间距、层级
3. **忠实实现**：按图还原为前端代码
4. 不可跳过图片生成步骤直接写代码

## 交付结果

- 可运行的前端代码
- 与设计图高度一致的视觉还原

## 默认边界

- **读文件**：是
- **写文件**：是
- **执行命令**：否
- **网络**：否

## 与相邻 Skill 的区别

| Skill | 区别 |
| --- | --- |
| `web.frontend-design` | 定设计方向和审美，本 Skill 是"图片→代码"视觉还原 |
| `web.frontend-implementation` | 实现组件和交互，本 Skill 偏视觉还原链路 |
| `web.brandkit` | 品牌视觉体系生成，本 Skill 是页面级代码实现 |

## 行为案例

### 案例 1：典型 Landing Page 还原

**输入**：用户提供设计参考图，要求"把这张 landing page 设计还原成代码"。

**预期行为**：
1. 先深度分析设计图（排版/配色/间距/层级/动效）
2. 逐区域还原为前端代码
3. 保持视觉高度一致
4. 产出可运行的前端代码

### 案例 2：无参考图的任务

**输入**：用户说"帮我做一个好看的 SaaS landing page"但没有参考图。

**预期行为**：
1. 先让 AI 生成设计参考图
2. 分析图片后再实现
3. 不跳过图片生成步骤直接写代码
