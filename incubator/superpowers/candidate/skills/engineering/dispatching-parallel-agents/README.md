# Dispatching Parallel Agents（派发并行代理）

## 一句话定位

当面对 2+ 个独立任务时，并发派发多个隔离上下文的专用代理，并行执行。

## 适用场景

- 多个测试文件因不同根因失败。
- 多个子系统独立损坏。
- 每个问题可以在不参考其他问题上下文的情况下被理解和修复。

## 不适用场景

- 失败可能相关（修一个可能修全部）。
- 需要完整系统状态才能理解问题。
- 代理会互相干扰（编辑同一文件、共享资源）。
- 探索性排障——你还不知道问题是什么。

## 执行流程

1. 按问题领域分组——识别独立域。
2. 为每个域创建聚焦的代理任务（范围 + 目标 + 约束 + 输出）。
3. 在同一响应中并发派发。
4. 代理返回后审查、核实无冲突、集成。

## 与领域 Skill 的关系

并行代理编排工作；领域 Skill 执行具体能力。派发时代理 prompt 中注入对应领域 Skill 的知识。
